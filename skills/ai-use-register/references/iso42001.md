# Mapping to ISO/IEC 42001

ISO/IEC 42001:2023 is a management system standard for AI. Annex A lists controls. The register maps each system to the Annex A control ids that evidence how it is managed, and records gaps where one should exist and does not.

The titles below are short paraphrases for orientation. Check the published standard for the authoritative wording. The validator accepts only these ids.

## How to map

- Map a control only where there is evidence or a stated practice that meets it. Do not map aspirations.
- Typical mappings: a vendor model API implies A.10.3; a customer-facing chatbot implies A.8.2 and A.9.4; anything scoring people implies A.5.2, A.5.4 and A.6.2.4; logging implies A.6.2.8; monitoring implies A.6.2.6; training data implies A.7.x.
- Put missing practices in `iso42001.gaps` as plain sentences naming the control. Gaps are useful; do not hide them.
- Mapping to the controls does not mean the organisation is certified or conforms to the standard.
